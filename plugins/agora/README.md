# agora: έρευνα αγοράς

Plugin του GitHub Copilot που σε βοηθά να αποφασίσεις **ποιο προϊόν να αγοράσεις**, π.χ. καφετιέρα, laptop ή ηλεκτρική συσκευή, από τη σκοπιά ενός αγοραστή στην Ελλάδα.

## Χρήση

```text
/agora Ποια καφετιέρα espresso να πάρω έως 400 €;
/agora Laptop για φοιτητή που δουλεύει CAD
```

Φορτώνεται και αυτόματα για ερωτήσεις όπως «ποιο να αγοράσω», «σύγκρινε», «έρευνα αγοράς» ή «skroutz».

## Τι κάνει

1. Ρωτά πρώτα, μία-μία, τη χρήση, τον προϋπολογισμό και τις απαραίτητες απαιτήσεις.
2. Διαβάζει με τον browser της εφαρμογής, στο πλαϊνό πάνελ:
   - Skroutz, για τιμές και κριτικές·
   - Reddit, για εμπειρίες κατόχων·
   - απομαγνητοφωνήσεις από YouTube·
   - ανεξάρτητα τεστ·
   - τιμές ανταλλακτικών.
3. Βγάζει μια λίστα υποψηφίων και, για 2–3 φιναλίστ, συγκεντρώνει στοιχεία σε βάθος.
4. Βαθμολογεί με κριτήρια που συμφωνείτε μαζί.
5. Παραδίδει αναφορά HTML, στα ελληνικά, με την επιλογή, την τιμή, πίνακες σύγκρισης και τις πηγές.

## Απαιτήσεις

- Η **εφαρμογή GitHub Copilot**. Το skill χρησιμοποιεί τον browser του πλαϊνού πάνελ και ερωτήσεις προς τον χρήστη. Στο σκέτο Copilot CLI χωρίς browser η έρευνα είναι περιορισμένη.
- Δεν χρειάζεται Python ή άλλη εγκατάσταση.

## Σημειώσεις

- Οι τιμές αλλάζουν. Η αναφορά γράφει την ημερομηνία ελέγχου.
- Οι εκτιμήσεις, π.χ. κόστος λειτουργίας και διάρκεια ζωής, σημειώνονται ως εκτιμήσεις.
