# Αναζήτηση νομικής βάσης και ΦΕΚ

## Εργαλεία `fek_*` (MCP server `nomos`)

Διαβάζουν τα ΦΕΚ μέσω του ανοιχτού API του search.et.gr (Εθνικό Τυπογραφείο), χωρίς σύνδεση.

| Ανάγκη | Κλήση |
| --- | --- |
| Σε ποιο ΦΕΚ δημοσιεύτηκε μια πράξη | `fek_find` με ref `4624/2019` ή `π.δ. 80/2016` |
| Κείμενο άρθρου, όπως δημοσιεύτηκε | `fek_text` με ref `4624/2019`, article `11` |
| Φράση μέσα σε ένα ΦΕΚ | `fek_text` με ref `Α 91/2023`, grep `έναρξη ισχύος` |
| ΦΕΚ που περιέχουν έναν όρο | `fek_search` με text `4624/2019`, issue `Β`, date_from `2025-01-01` |
| Τροποποιήσεις και διασταύρωση | skill `elegxos-tropopoiiseon` |

- Το `fek_text` δίνει το κείμενο **όπως δημοσιεύτηκε**, όχι το ενοποιημένο.
- Το `fek_search` λειτουργεί καλύτερα με αριθμό πράξης («N/ΕΕΕΕ») ή μεμονωμένους όρους. Οι πολυλεκτικές φράσεις δίνουν ασταθή αποτελέσματα.
- Χρησιμοποίησε μόνο συνδέσμους που επιστρέφουν τα εργαλεία (PDF και σελίδα ΦΕΚ). Μην τους κατασκευάζεις.
- Αν τα εργαλεία δεν είναι διαθέσιμα, το ίδιο κάνει το CLI `python tools/fek.py <find|text|amendments|search|crosscheck>` από τη ρίζα του αποθετηρίου nomos.

## Σειρά προτεραιότητας πηγών

1. **ΦΕΚ, μέσω `fek_*`**: η τελική πηγή για το δημοσιευμένο κείμενο.
   - **Τεύχος Α'**: νόμοι και Προεδρικά Διατάγματα.
   - **Τεύχος Β'**: υπουργικές και κοινές υπουργικές αποφάσεις (ΚΥΑ).
2. **taxheaven.gr, μέσω `fek_crosscheck`**: κωδικοποιημένο κείμενο νόμων. **Μόνο για διασταύρωση.** Κάθε απόκλιση επιβεβαιώνεται στο ΦΕΚ.
3. **Ιστότοποι υπουργείων, ΑΑΔΕ, e-ΕΦΚΑ**: εγκύκλιοι και ερμηνευτικές οδηγίες. Δεν υπερισχύουν του νόμου.
4. **EUR-Lex**: κανονισμοί και οδηγίες της ΕΕ.
5. **Αναζήτηση στο web** (π.χ. e-nomothesia.gr, lawspot.gr): **μόνο για εντοπισμό** του αριθμού μιας πράξης. Τα κείμενά τους δεν είναι πάντα ενοποιημένα.

**Δεν χρησιμοποιούνται:**

- **kodiko.gr**: απαιτεί σύνδεση και μπλοκάρει την αυτόματη ανάγνωση.
- **search.et.gr με web fetch**: είναι εφαρμογή JavaScript και δεν επιστρέφει κείμενο. Τα εργαλεία `fek_*` διαβάζουν τα ίδια δεδομένα απευθείας.

**Ποτέ τελική πηγή:** blogs, φόρουμ, ειδησεογραφικά sites. Μπορούν μόνο να υποδείξουν πού να ψάξεις.

## Ροή εντοπισμού

1. **Γνωστός αριθμός πράξης:** `fek_find`, μετά `fek_text` με article.
2. **Άγνωστος αριθμός:** βρες υποψήφιο αριθμό με αναζήτηση στο web ή με `fek_search`. Επιβεβαίωσέ τον με `fek_find` και διάβασε το άρθρο με `fek_text`.
3. **Υπουργικές αποφάσεις και ΚΥΑ:** `fek_search` με issue `Β`, μετά `fek_text` με ref `Β <αριθμός>/<έτος>`. Τα `fek_find` και `fek_amendments` καλύπτουν μόνο πράξεις με αριθμό (ν., π.δ., ν.δ. κ.λπ.).

## Πρακτικές

- Κατέγραψε για κάθε διάταξη: πράξη, άρθρο, παράγραφο, ΦΕΚ (τεύχος, αριθμός, ημερομηνία), σελίδα και σύνδεσμο, όπως τα δίνουν τα εργαλεία.
- Αν ένα εργαλείο αναφέρει PDF χωρίς κείμενο (σαρωμένο), σημείωσέ το, ζήτησε από τον χρήστη να το ελέγξει και μείωσε τη βεβαιότητα.
- Αν η πηγή δεν βρεθεί, γράψε «δεν βρέθηκε». Μην συμπληρώνεις από μνήμη.
- Μετά τον εντοπισμό, ο έλεγχος ισχύος γίνεται με το skill `elegxos-tropopoiiseon`.
